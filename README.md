# 올인원 교사 도우미 — 업데이트 배포 저장소

이 저장소는 **올인원 교사 도우미**의 새 설치 파일을 내려받는 자리입니다. 프로그램 안의 `[지금 업데이트]` 가 이 저장소의 **Releases** 에서 설치 파일을 받아, 서명된 안내 파일에 적힌 크기·SHA-256 과 대조한 뒤 설치합니다.
설치 파일과 대응 소스는 [Releases](https://github.com/dhsy3206/aio-releases/releases) 에 있습니다(저장소 파일 목록에는 없습니다).

> ⚠ GitHub 가 릴리스마다 저절로 붙이는 **"Source code (zip / tar.gz)"** 는 이 저장소의 `README.md`·`NOTICE.md` 일 뿐 **프로그램의 소스도, 오픈소스 부품의 대응 소스도 아닙니다.** 대응 소스는 릴리스에 올려 둔 `AIO_*_corresponding_source_*.zip` 입니다.

- 저작권자 하늘을 보자 ('하늘을 보자' 는 저작자의 이명입니다) · 판매·배포 동해삼육사회적협동조합 · 구입·문의 https://smartstore.naver.com/dhsy2018
- 이 프로그램은 구입한 기관·이용자의 업무 사용을 위한 것이며, 설치한 뒤 인증키 없이는 5일 동안만 실행됩니다. 저작권법이 허용하는 이용을 뺀 무단 복제·재배포·소스 추출·인증 우회를 금합니다.
- **제3자 오픈소스 구성요소**(FFmpeg · Ghostscript · Qt · PySide6 · lxml 등)에는 위 제한이 적용되지 않으며 각자의 라이선스를 따릅니다. 라이선스 전문은 설치 폴더의 `_internal\licenses\` 에 있고, FFmpeg · Ghostscript 의 대응 소스는 각 릴리스에 함께 올려 둡니다(주소: https://github.com/dhsy3206/aio-releases/releases).
- Claude·Claude Code 는 Anthropic, ChatGPT·Codex 는 OpenAI, Gemini·Antigravity 는 Google 의 이름(상표)입니다. 이 프로그램은 그 회사들과 제휴·후원·보증 관계가 없습니다.
- 설치 파일에는 코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있습니다. 릴리스의 `SHA256SUMS.txt` 와 받은 파일의 해시를 견주어 확인하세요(PowerShell: `Get-FileHash <파일> -Algorithm SHA256`).
- 업데이트 확인 때 프로그램이 새 판 안내 파일(`dhsy3206.github.io`)에, `[지금 업데이트]` 를 누르면 이 저장소의 릴리스 자산(`github.com` · `release-assets.githubusercontent.com`)에 접속하므로 **IP 주소와 프로그램 이름·판**이 GitHub 서버에 전달될 수 있습니다(경우에 따라 `objects.githubusercontent.com` 도 쓰입니다). 학생 정보는 보내지 않습니다. 자세한 내용은 설치 폴더의 `_internal\docs\개인정보_처리방침.md` 6-1 을 보세요.
- 자동 업데이트(`[지금 업데이트]`)는 **설치 프로그램의 기본 위치**(`%APPDATA%\All-in-one_document_assistant`)에 설치한 경우를 위한 것입니다. 다른 위치에 설치해 쓰신다면 [판매처 안내](https://smartstore.naver.com/dhsy2018)에서 새 설치 파일을 받아 직접 설치하세요.

자세한 이용 안내는 [NOTICE.md](NOTICE.md) 를 보세요.
